# Convex functions

- `schema.ts`: tables (restaurants, groups, responses, waitlist)
- `groups.ts`: create and look up a group by its 4-letter code
- `responses.ts`: save one person's answers, list a group's answers
- `pickLogic.ts`: the matching rules, plain TypeScript so it can be tested
- `pick.ts`: `getPick` query that runs the rules for a group
- `waitlist.ts`: landing page signups
